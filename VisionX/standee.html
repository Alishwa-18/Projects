Fall 2025 · Final Project
VisionX is a browser-based, real-time computer vision application that runs entirely on the client-side — no server, no upload, no delay. It uses MediaPipe Hands to detect 21 hand landmarks and classify 12+ gestures live, a custom pixel-clustering algorithm to extract dominant colors and compute perceptual metrics, and face-api.js with TinyFaceDetector to predict age, gender, and 7 emotional states with landmark overlay. All three vision pipelines run in real-time at 20–30 FPS directly from the webcam inside a single HTML file.

Core Modules
🤚
Hand Gesture Recognition
Tracks 21 hand landmarks in real-time using MediaPipe's ML graph. Custom rule-based classifier detects 12+ gestures including Thumbs Up, Peace, Shaka, Fist, OK, and more.
MediaPipe Hands
🎨
Live Color Analyzer
Extracts dominant colors from the webcam feed every 180ms using pixel quantization (bit-shifting). Shows HSL, brightness, temperature, variance, and named color matching.
Canvas Pixel API
👤
Face & Person Analysis
Detects faces with TinyFaceDetector, overlays 68 landmarks, and simultaneously estimates age, gender, and 7 emotional expressions (happy, sad, angry, surprised, etc.).
face-api.js / TensorFlow.js
⚡
Real-Time Processing
All inference runs in the browser using WebAssembly and WebGL. No data ever leaves the device — zero latency, complete privacy, works offline after initial load.
WebAssembly + WebGL
🧠
Multi-Modal Pipeline
